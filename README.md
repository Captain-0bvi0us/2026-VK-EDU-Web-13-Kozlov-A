# 2026-VK-EDU-Web-13-Kozlov-A

В репозитории — материалы по курсу «WEB-технологии» и выполненные домашние задания.

## ДЗ1: статическая вёрстка (CupOfQ)

Вёрстка лежит в каталоге `public/`. Используются **Bootstrap 5.3** и собственные стили, все файлы подключены **локально** из `public/static/`.

### Как открыть

Откройте в браузере файл `public/index.html` (двойной щелчок или «Открыть с помощью…» → браузер). Остальные страницы переходятся по ссылкам в шапке и в контенте.

Для проверки адаптива удобно открыть инструменты разработчика (F12) и переключать ширину окна (около 375px, 768px, ≥1200px).

### Страницы (маршруты в статике — имена файлов)

| Файл | Назначение |
|------|------------|
| `public/index.html` | Главная: список новых вопросов, пагинация, виджет голосования (три состояния на примерах карточек) |
| `public/question.html` | Страница одного вопроса: ответы, пагинация ответов, форма ответа, отметка «правильный ответ» |
| `public/ask.html` | Форма нового вопроса |
| `public/login.html` | Вход |
| `public/signup.html` | Регистрация |
| `public/profile.html` | Настройки профиля (аватар, email, отображаемое имя) |
| `public/tag.html` | Листинг по тегу (демо для ссылок с тегов) |
| `public/base.html` | Тот же каркас layout + навигация по всем страницам (ориентир для копирования структуры) |

Бренд и оформление: **CupOfQ**, тёплая палитра (крем / абрикос / терракота / шоколад). Фавикон: `public/static/img/favicon.svg`.
